## 📋 प्रस्तावना एवं उद्देश्य (Preamble & Scope)

**हिन्दी विकिपीडिया चर्चा समापन एवं पुरालेखन उपकरण** एक आधिकारिक-स्तरीय, क्लाइंट-आधारित (Client-side) वेब अनुप्रयोग है। इसका मुख्य उद्देश्य [हिन्दी विकिपीडिया (hi.wikipedia.org)](https://hi.wikipedia.org) के विभिन्न विचार-विमर्श मंचों—यथा **चौपाल**, **प्रबंधक सूचनापट**, **पृष्ठ हटाने हेतु चर्चा (VFD)** तथा अन्य वार्ता पृष्ठों—पर संपन्न अथवा कालावतीत हो चुकी परिचर्चाओं का विधिसम्मत समापन (Closing) करना तथा उन्हें सुव्यवस्थित रीति से पुरालेख उप-पृष्ठों में स्थानांतरित (Archiving) करना है।

यह उपकरण विकिमीडिया फ़ाउंडेशन के तकनीकी एवं सुरक्षा मानकों के पूर्णतः अनुरूप है। यह किसी भी मध्यवर्ती सर्वर (Third-party Server) अथवा संवेदनशील क्रेडेंशियल्स के भंडारण के बिना, सीधे विकिमीडिया REST एवं Action API के माध्यम से सुरक्षित रूप से कार्य निष्पादित करता है।

## 🔐 अधिकृत प्रमाणीकरण एवं सुरक्षा व्यवस्था (Authentication & Security Standards)

उपकरण में दुरुपयोग की रोकथाम, विकिपीडिया की अखंडता के संरक्षण तथा विकिमीडिया सुरक्षा नीतियों के अनुपालन हेतु त्रि-स्तरीय सुरक्षा व्यवस्था स्थापित की गई है:

1. **विकिमीडिया OAuth 2.0 (PKCE) प्रमाणीकरण:**
   - उपकरण उद्योग-मानक **OAuth 2.0 Proof Key for Code Exchange (PKCE)** प्रोटोकॉल पर आधारित है।
   - सदस्य `विकिमीडिया खाते से लॉगिन करें` बटन के माध्यम से सीधे विकिमीडिया के आधिकारिक प्रमाणीकरण पृष्ठ पर पुनर्निर्देशित होते हैं तथा अनुमति उपरांत स्वतः वापस आकर अधिकृत होते हैं।
   - इस प्रक्रिया में किसी भी स्तर पर पासवर्ड दर्ज करने अथवा संग्रहीत करने की आवश्यकता नहीं होती (100% Password-Free)।

2. **न्यूनतम पात्रता एवं स्वतः-स्थापित सदस्य परीक्षण (Autoconfirmed Gate):**
   - बर्बरता अथवा अनाधिकृत हस्तक्षेप को नियंत्रित करने हेतु, यह उपकरण विकिपीडिया Action API द्वारा सदस्य के खाते की पात्रता का पूर्व-सत्यापन करता है।
   - **न्यूनतम अर्हता:** सदस्य का खाता न्यूनतम **4 दिवस पुराना** होना चाहिए तथा कम से कम **10 वैध संपादन** होने अनिवार्य हैं (स्वतः स्थापित / Autoconfirmed स्तर)। अपात्र अथवा अनाधिकृत खातों के लिए उपकरण की संपादन सुविधाएँ स्वतः अवरुद्ध (Gated) रहती हैं।

3. **संपादन उत्तरदायित्व एवं श्रेय (Attribution & Accountability):**
   - प्रत्येक समापन तथा पुरालेखन संपादन में अधिकृत सदस्य का मानक विकिपीडिया हस्ताक्षर (`--~~~~`) स्वतः अंकित होता है तथा संपादन सारांश में उपकरण का संदर्भ स्पष्ट रूप से प्रलेखित रहता है, जिससे विकिपीडिया इतिहास में संपादन का श्रेय सीधे वास्तविक सदस्य के खाते को प्राप्त होता है।

## ✨ मुख्य तकनीकी विशिष्टताएँ (Key Features)

### 1. हिन्दी भाषा एवं देवनागरी विशिष्ट अनुकूलन
- **देवनागरी अंक रूपांतरण:** देवनागरी अंकों (`०-९`) को अंतरराष्ट्रीय अंकों (`0-9`) में स्वतः रूपांतरित कर सटीक कालावधि (Days Inactive) की गणना।
- **हिन्दी पंचांग एवं मास विश्लेषण:** जनवरी से दिसम्बर (एवं वैकल्पिक मानक वर्तनी जैसे फ़रवरी/फरवरी, सितम्बर/सितंबर आदि) युक्त हस्ताक्षरों की स्वतः पहचान।
- **मानकीकृत हिन्दी साँचे:** `{{चर्चा शीर्ष}}`, `{{चर्चा तल}}`, `{{पुरालेख पेटी}}` आदि का नीति-सम्मत प्रारूपण।

### 2. बुद्धिमत्तापूर्ण पुरालेखन प्रबंधन (Intelligent Archiving)
- **विद्यमान पुरालेखों की स्वतः खोज:** मूल पृष्ठ के अंतर्गत निर्मित समस्त पुरालेख उप-पृष्ठों (उदा: `/पुरालेख 1`, `/पुरालेख 2`) का आकार (KB) सहित स्वतः संकलन।
- **आकार सीमा नियंत्रण:** पुरालेख पृष्ठ का आकार विहित सीमा (यथा 100 KB) पार होने पर स्वचालित रूप से नवीन अनुवर्ती पुरालेख उप-पृष्ठ का सुझाव।
- **अंतरण सूचना (Stub Insertion):** पुरालेख में स्थानांतरित अनुभागों के स्थान पर मूल पृष्ठ पर स्वतः संदर्भ कड़ी स्थापित करना।

### 3. सहायक प्रशासनिक मॉड्यूल (Administrative Utilities)
- **चर्चा पुनर्उद्घाटन (Reopen):** पूर्व में बंद की गई चर्चाओं से समापन साँचों को विधिवत हटाकर पुनः सक्रिय करना।
- **अनुभाग स्थानांतरण (Thread Relocation):** किसी परिचर्चा को अन्य संगत वार्ता अथवा परियोजना पृष्ठ पर स्थानांतरित करना तथा पूर्व स्थान पर पुनर्निर्देशन सूचना अंकित करना।
- **अप्रासंगिक/अनुपयुक्त चर्चा विलोपन (Cut/Delete):** स्पैम अथवा विकिपीडिया नीतियों के प्रतिकूल अनुभागों को पृष्ठ से हटाना।
- **पुरालेख अनुक्रमणिका निर्माण:** विकिटेबल अथवा बुलेटेड सूची के प्रारूप में संपूर्ण पुरालेखों की व्यवस्थित अनुक्रमणिका (Index) तैयार करना।

### 4. स्वचालित बॉट संक्रिया (Bot Automation Mode)
- **बॉट ध्वज (`bot=1`):** प्राधिकृत बॉट खातों हेतु हाल में हुए परिवर्तन (Recent Changes) सूची को अप्रभावित रखने की सुविधा।
- **गति नियंत्रण (Rate Limiting):** विकिमीडिया बॉट नीतियों के अनुरूप 3s, 5s अथवा 10s का अनिवार्य अंतराल।
- **आपातकालीन कार्य-विराम (Emergency Kill Switch):** किसी भी विसंगति की स्थिति में संक्रिया को एक क्लिक में तत्काल रोकने की व्यवस्था।

## 🏛️ मानक संचालन प्रक्रिया (Standard Operating Procedure - SOP)

```
[1. प्रमाणीकरण] ──> [2. पृष्ठ चयन एवं विश्लेषण] ──> [3. अनुभाग एवं कार्य चयन] ──> [4. पूर्वावलोकन एवं सहेजना]
  OAuth 2.0 /          विकिपीडिया पृष्ठ दर्ज          समापन / पुरालेखन /          विकिटेक्स्ट सत्यापन एवं
  common.js            करके डेटा लोड करें            स्थानांतरण निर्देश            विकिपीडिया पर सुरक्षित संपादन
```

### चरण 1: प्रमाणीकरण (Authentication)
1. पृष्ठ के शीर्ष पर स्थित **"विकिमीडिया खाते से लॉगिन करें"** बटन पर क्लिक करें।
2. आधिकारिक विकिमीडिया पृष्ठ पर अनुमति प्रदान करने के उपरांत उपकरण में स्वतः प्रमाणीकरण पूर्ण हो जाएगा।
3. प्रणाली आपकी सदस्यता स्तर (स्वतः-स्थापित अथवा उच्चतर) का स्वतः सत्यापन कर कार्यक्षेत्र को सक्रिय कर देगी।

### चरण 2: लक्षित पृष्ठ का चयन एवं विश्लेषण (Loading Target Page)
1. इनपुट बॉक्स में अभीष्ट चर्चा पृष्ठ का शीर्षक प्रविष्ट करें (यथा `विकिपीडिया:चौपाल`, `विकिपीडिया:प्रबंधक सूचनापट` आदि) अथवा ड्रॉपडाउन सूची से चयन करें।
2. **"पृष्ठ लोड करें"** बटन दबाएँ। उपकरण पृष्ठ के समस्त अनुभागों, निष्क्रिता अवधि तथा हस्ताक्षरों का विश्लेषण प्रस्तुत करेगा।

### चरण 3: परिचर्चाओं का चयन एवं संक्रिया (Action Selection)
1. प्रस्तुत तालिका में से उन अनुभागों को चिह्नित करें जिन पर कार्यवाही अपेक्षित है।
2. अभीष्ट कार्य का चयन करें:
   - **चर्चा समाप्त करें:** उपयुक्त निष्कर्ष (यथा *सफल*, *असफल*, *सहमति बनी*) तथा टिप्पणी दर्ज करें।
   - **पुरालेख में भेजें:** अभीष्ट पुरालेख उप-पृष्ठ चुनें अथवा स्वतः अनुशंसित पृष्ठ स्वीकार करें।
   - **अन्य कार्यवाही:** स्थानांतरण अथवा निष्कासन विकल्प चुनें।

### चरण 4: पूर्वावलोकन, सत्यापन एवं संपादन (Preview & Execution)
1. **"पूर्वावलोकन देखें"** पर क्लिक कर रूपांतरित विकिटेक्स्ट की शुद्धता का निरीक्षण करें।
2. **"सीधे विकिपीडिया पर सहेजें"** बटन पर क्लिक करके संपादन को सीधे पृष्ठ पर लागू करें, अथवा विकिटेक्स्ट कॉपी करके मैन्युअल रूप से सुरक्षित करें।

## 💻 संस्थापन एवं परिनियोजन (Installation & Deployment)

### 1. विकिपीडिया इन-विकि स्क्रिप्ट संस्थापन (In-Wiki Script)
हिन्दी विकिपीडिया के वार्ता पृष्ठों पर इस उपकरण का सीधा शॉर्टकट प्राप्त करने हेतु अपने विकिपीडिया खाते के [Special:MyPage/common.js](https://hi.wikipedia.org/wiki/Special:MyPage/common.js) पृष्ठ में निम्नलिखित निर्देश दर्ज करें:

```javascript
// [[विकिपीडिया:चर्चा समापन एवं पुरालेखन उपकरण]]
mw.loader.load('https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/DiscussionArchiver.js');
```

### 2. GitHub Pages पर लाइव परिनियोजन (Hosting)
यह संपूर्ण परियोजना क्लाइंट-साइड संचित है। इसे किसी भी GitHub रिपॉजिटरी में निम्नवत परिनियोजित किया जा सकता है:

```bash
git clone https://github.com/vikrampratap-wiki/Discussion-arcriever-tool.git
cd Discussion-arcriever-tool
# GitHub Settings -> Pages में जाकर Source को 'Deploy from branch (main / root)' पर सेट करें।
```

लाइव वेब पता:
> **https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/**

### 3. स्थानीय परिवेश में निष्पादन (Local Server Execution)
स्थानीय प्रणाली पर परीक्षण हेतु शून्य-निर्भरता (Zero-dependency) Python सर्वर उपलब्ध है:

```bash
python3 server.py --port 8080
```
ब्राउज़र में निम्न यूआरएल खोलें: `http://localhost:8080`
