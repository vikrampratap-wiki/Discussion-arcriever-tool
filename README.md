## 🇮🇳 परिचय (Overview)

**हिन्दी विकिपीडिया चर्चा समापन एवं पुरालेखण टूल** एक आधुनिक, तीव्र एवं उपयोगकर्ता-अनुकूल वेब उपकरण है जिसे विशेष रूप से [हिन्दी विकिपीडिया](https://hi.wikipedia.org) के वार्ता पृष्ठों (जैसे चौपाल, प्रबंधक सूचनापट, पृष्ठ हटाने हेतु चर्चा आदि) पर पुरानी चर्चाओं को समाप्त (Close) करने एवं उन्हें सुव्यवस्थित रूप से पुरालेख (Archive) में स्थानांतरित करने हेतु विकसित किया गया है।

यह टूल पूरी तरह **क्लाइंट-साइड (Client-side)** कार्य करता है तथा MediaWiki Action API (CORS सक्षम) का उपयोग करता है। इसलिए इसे **GitHub Pages** पर 100% निःशुल्क और बिना किसी बैकएंड सर्वर के लाइव होस्ट किया जा सकता है!

## ✨ मुख्य विशेषताएँ (Key Features)

1. **हिन्दी विकिपीडिया के लिए विशेष रूप से अनुकूलित:**
   - **देवनागरी अंकों का स्वतः रूपांतरण:** देवनागरी अंक (`०-९`) को स्वतः अंतरराष्ट्रीय अंकों (`0-9`) में परिवर्तित कर सही विश्लेषण।
   - **हिन्दी महीनों की पहचान:** जनवरी से दिसम्बर (एवं वैकल्पिक वर्तनी जैसे फ़रवरी/फरवरी, सितम्बर/सितंबर) के आधार पर पुरानी चर्चाओं की स्वतः आयु गणना (Days inactive)।
   - **हिन्दी साँचों का समर्थन:** `{{चर्चा शीर्ष}}`, `{{चर्चा तल}}`, `{{पुरालेख पेटी}}` आदि का मानक प्रारूपण।

2. **स्मार्ट पुरालेख प्रबंधन (Smart Archiving):**
   - **मौजूदा पुरालेखों की स्वतः खोज:** पृष्ठ के सभी मौजूदा पुरालेखों (जैसे `/पुरालेख 1`, `/पुरालेख 2`) को ढूंढकर उनके आकार (KB) के साथ प्रदर्शित करना।
   - **आकार सीमा पर स्वतः विभाजन:** 100 KB (या इच्छित सीमा) पार होने पर स्वतः नया पुरालेख उप-पृष्ठ सुझाना।
   - **स्थान परिवर्तन सूचना (Stub):** पुरालेख में ले जाए गए अनुभागों के स्थान पर मूल पृष्ठ पर स्वतः कड़ी छोड़ना।

3. **सुरक्षा एवं विकिमीडिया सेंट्रल लॉगिन (100% Password-Free & CentralAuth SUL):**
   - **पूर्णतः पासवर्ड-रहित (Zero-Password Security):** विकिमीडिया नीतियों के अनुरूप यह उपकरण कभी भी पासवर्ड नहीं मांगता।
   - **विकिमीडिया सेंट्रल सत्यापन (CentralAuth SUL):** `meta.wikimedia.org` एवं `hi.wikipedia.org` API द्वारा सीधे सार्वजनिक खाता सत्यापन।
   - **स्वतः स्थापित सदस्य सुरक्षा जाँच (Autoconfirmed Check):** उपकरण विकिपीडिया Action API द्वारा उपयोगकर्ता के खाते की आयु (>= 4 दिन) और कुल संपादन (>= 10) की स्वतः पुष्टि करता है ताकि बर्बरता को रोका जा सके।
   - **सीधे विकिपीडिया पर सहेजना (Direct Browser Session Save):** आपके ब्राउज़र के सक्रिय विकिपीडिया सत्र के माध्यम से 1-क्लिक में सुरक्षित संपादन।

4. **स्वचालित बॉट मोड (Bot Automation Mode):**
   - **बॉट ध्वज (`bot=1`):** हाल में हुए परिवर्तनों (Recent Changes) में अव्यवस्था से बचने के लिए बॉट संपादन ध्वज लागू करना।
   - **संपादन गति नियंत्रण (Throttling):** विकिपीडिया बॉट नीतियों के अनुरूप 3s / 5s / 10s का विनम्र अंतराल।
   - **आपातकालीन रोक (Kill Switch):** कभी भी बॉट कार्य को तुरंत रोकने की सुविधा।

5. **एकल ऑफ़लाइन फ़ाइल बंडल (Single-File All-in-One):**
   - संपूर्ण HTML, CSS और जावास्क्रिप्ट को समाहित करने वाली एकल फ़ाइल **`DiscussionArchiver_Standalone.html`** जिसे कहीं भी ऑफ़लाइन चलाया जा सकता है।

6. **सहायक उपकरण (Mini-Tools) एवं चर्चा काटना/हटाना:**
   - बंद चर्चा को पुनः खोलना (Reopen - नेस्टेड साँचों की पूर्ण सफ़ाई)।
   - चर्चा को अन्य वार्ता या परियोजना पृष्ठ पर स्थानांतरित करना (Move Thread / Cut to another page) एवं पुनर्निर्देशन स्टब छोड़ना।
   - चयनित अनुपयुक्त या स्पैम चर्चाओं को पृष्ठ से काटना/हटाना (Cut / Delete Threads)।
   - रिक्त अनुभागों की स्वतः सफ़ाई।
   - पृष्ठ के शीर्ष पर `{{पुरालेख पेटी}}` जोड़ना।
   - विकिटेबल अथवा बुलेट सूची में पुरालेख अनुक्रमणिका (Index) तैयार करना।

7. **आधुनिक इंटरफ़ेस:**
   - डार्क एवं लाइट थीम (Dark/Light mode)।
   - रीयल-टाइम खोज एवं बहु-अनुभाग चयन (Select All / Invert / Older than N days)।
   - विकिटेक्स्ट पूर्वावलोकन मोडल तथा 1-क्लिक क्लिपबोर्ड कॉपी।

## 🚀 GitHub Pages पर लाइव होस्ट करने की विधि (Deploy to GitHub Pages)

यह टूल पूरी तरह स्टैटिक HTML/CSS/JS आधारित है। इसे GitHub Pages पर लाइव करने के चरण:

1. अपने GitHub खाते में एक नया रिपॉजिटरी बनाएँ (उदा: `hindi-wiki-discussion-archiver`)।
2. इस डायरेक्टरी की सभी फ़ाइलों को रिपॉजिटरी में पुश (Push) करें:
   ```bash
   git remote add origin https://github.com/vikrampratap-wiki/Discussion-arcriever-tool.git
   git push -u origin main
   ```
   *(या आप डायरेक्टरी में दिए गए `./push_to_github.sh` स्क्रिप्ट को भी चला सकते हैं!)*

3. GitHub पर अपने रिपॉजिटरी पेज पर जाएँ:
   - **Settings** ➔ **Pages** पर क्लिक करें।
   - **Build and deployment** > **Source** में `Deploy from a branch` चुनें।
   - **Branch** में `main` और फ़ोल्डर `/ (root)` चुनकर **Save** पर क्लिक करें।

4. 1-2 मिनट में आपकी वेबसाइट लाइव हो जाएगी:
   ```
   https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/
   ```

## 💻 स्थानीय कंप्यूटर पर चलाने की विधि (Run Locally)

### विकल्प A: अंतर्निहित Python सर्वर (अनुशंसित)
यह रिपॉजिटरी बिना किसी बाहरी पैकेज (Zero dependencies) के Python के इन-बिल्ट सर्वर के साथ आती है:

```bash
# रिपॉजिटरी डायरेक्टरी में जाएँ
cd hindi-wiki-discussion-archiver

# सर्वर चलाएँ (यह स्वतः ब्राउज़र में खोल देगा)
python3 server.py
```
या किसी विशिष्ट पोर्ट पर:
```bash
python3 server.py --port 8080
```
ब्राउज़र में खोलें: `http://localhost:8080`

### विकल्प B: सीधे ब्राउज़र में खोलें
चूँकि विकिपीडिया Action API CORS (`origin=*`) का समर्थन करता है, आप सीधे `index.html` फ़ाइल पर डबल-क्लिक करके भी इसे किसी भी ब्राउज़र (Chrome, Firefox, Edge) में चला सकते हैं!

## 👥 अन्य सदस्यों द्वारा उपयोग (Multi-User Community Usage)

यह उपकरण केवल एक सदस्य के लिए सीमित नहीं है, बल्कि **हिन्दी विकिपीडिया का कोई भी स्वतः स्थापित सदस्य (Autoconfirmed User) या प्रबंधक** इसे अपने खाते से आसानी से उपयोग कर सकता है:

### 1. सीधे वेब लिंक द्वारा (Direct Web App)
कोई भी सदस्य सीधे लाइव वेबसाइट पर जा सकता है:
> 🔗 **https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/**

- हेडर में **"🔐 विकिमेडिया लॉगिन / पात्रता"** पर क्लिक करके अपना सदस्य नाम दर्ज करें।
- टूल तुरंत विकिपीडिया Action API से आपके खाते की स्वतः स्थापित स्थिति की पुष्टि कर देगा और आपके अधिकार सक्रिय हो जाएँगे।

### 2. सीधे किसी चर्चा पृष्ठ को लोड करना (URL Parameters)
किसी भी पृष्ठ अथवा सदस्य को सीधे लोड करने के लिए URL पैरामीटर्स का उपयोग करें:
```text
https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/?page=विकिपीडिया:चौपाल&user=आपका_सदस्य_नाम
```

### 3. विकिपीडिया में गैजेट / स्क्रिप्ट के रूप में जोड़ना (In-Wiki User Script)
यदि आप चाहते हैं कि विकिपीडिया पर कोई भी वार्ता पृष्ठ खोलते ही बाईं ओर 'उपकरण' (Tools) मेनू में इस टूल की कड़ी दिखे, तो अपने विकिपीडिया खाते के [Special:MyPage/common.js](https://hi.wikipedia.org/wiki/Special:MyPage/common.js) में निम्नलिखित एक पंक्ति जोड़ें:
```javascript
// [[विकिपीडिया:चर्चा समापन एवं पुरालेखण उपकरण]]
mw.loader.load('https://vikrampratap-wiki.github.io/Discussion-arcriever-tool/DiscussionArchiver.js');
```

## 🛠️ उपयोग के निर्देश (How to Use)

1. **पृष्ठ लोड करें:**
   - इनपुट बॉक्स में हिन्दी विकिपीडिया का कोई भी चर्चा पृष्ठ (उदा: `विकिपीडिया:चौपाल`, `सदस्य वार्ता:उदाहरण`) लिखें या त्वरित सूची से चुनें।
   - **"पृष्ठ लोड करें"** बटन पर क्लिक करें।
2. **अनुभाग चुनें:**
   - तालिका में से उन अनुभागों के चेकबॉक्स को चुनें जिन्हें आप समाप्त या पुरालेख में भेजना चाहते हैं।
   - आप फ़िल्टर (उदा: *30+ दिन पुराने*, *निष्क्रिय*) का भी उपयोग कर सकते हैं।
3. **कार्य चुनें:**
   - **चर्चा समाप्त करें:** निष्कर्ष और स्थिति चुनें, फिर **"पूर्वावलोकन देखें"** पर क्लिक करें।
   - **पुरालेख में भेजें:** लक्षित पुरालेख पृष्ठ (उदा: `/पुरालेख 1`) चुनें और **"स्थानांतरित करें"** पर क्लिक करें।
4. **सहेजें:**
   - पूर्वावलोकन मोडल में नए विकिटेक्स्ट को देखें और **"विकिटेक्स्ट कॉपी करें"** पर क्लिक करें।
   - **"विकिपीडिया पर संपादन खोलें"** बटन दबाकर सीधे विकिपीडिया पर पेस्ट करके सहेज दें।
